## 1. До старта: что именно проверяется

Реплей 167 реальных сделок B1 из прогона №7, цены из `observations.csv`,
после измеренных 3.25 % круглого рейса:

| вариант | результат |
|---|---|
| B1 + fee-cover 3.5 % | −4.93 % |
| B1, держать 5 с | −2.22 % |
| t0 + 5 с | −2.30 % |
| t0 + полоса 30.5–34.5 + 5 с + стоп −10 % | **+1.46 %** (n=1533) |

Медианная надбавка входа: B1 2.89 %, A 5.55 %, B3 0.00 %. Вывод до старта:
`delta ≥ 0.10` покупает чужое движение и продаёт его по +3.5 %.

Задача прогона — измерить латентность и стоимость исполнения, а не деньги.
30–60 сделок на книгу не разрешают ничего, порог +8 ₽ после Bonferroni
требует ~1 700 пар.
