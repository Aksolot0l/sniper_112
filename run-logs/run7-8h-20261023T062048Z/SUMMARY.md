## Как читать

1. Армы сравниваются только парно и только по монетам, которые торговали оба; сырые средние двух выборок на пересекающихся монетах — не тест.
2. Почасовая таблица показывает шум: если разница между армами меньше разброса между часами, это шум, а не эффект.
3. PnL не доказывает эджа. Решение принимается только по критерию выше; отрицательный знак у всех арм ожидаем и не является сюрпризом.
